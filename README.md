# taipan_data_plotter
A html+js web page for visualizing and quickly fitting data from triple-axis spectrometer Taipan

## 🚀 Installation and Usage:
No installation is needed.
Click the following URL:
[https://gcdengansto.github.io/taipan_data_plotter/]

Upload your Taipan data files, you will see the plots of all the uploaded data files.


## 🎯 Features
Quick plotting data
Showing the first rows for data checking
Quick fitting data with Gaussian
